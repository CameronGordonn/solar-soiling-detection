# docs/internal/

Working documents from the period when this was a team project at the Better Behavior
Foundation: onboarding, ownership, quarterly plans, handoffs, meeting briefs and drafts written
for specific people. They are kept as the record of how the work was run; only links to moved files were updated.

They are not maintained. Instructions in them (who to ask, what to run next, which data to pull)
describe the team and infrastructure at the time and will not work from this public snapshot.
For the current state of the results, read the [top-level README](../../README.md),
[CANONICAL_NUMBERS.md](../CANONICAL_NUMBERS.md) and the papers in [`paper/`](../../paper/).
